# 像素画生成器

> 把任意图片一键转成像素画 / 马赛克装饰画。单个 HTML 文件，零依赖，全部计算在你的浏览器里完成，**图片不会上传到任何服务器**。

[English](README.md) | **简体中文**

## 能做什么

- **10 种风格调色板**：经典像素（自动减色）、复古掌机（四色墨绿）、街机 16 色（PICO-8）、老电脑 CGA、黑白报纸、拼豆色卡（MARD 291）、拼豆全色卡（优肯 415）、霓虹赛博、落日暖调、冰川冷调
- **像素块数** 16 ~ 512 可调，附「头像 32 / 标准 64 / 精细 128 / 挂画 256 / 极致 512」快捷档
- **颜色数量** 8 ~ 512 色（自动减色、灰阶模式下生效）
- **亮度 / 对比度** 实时调节
- **Floyd–Steinberg 抖动**：照片和渐变图开一下，过渡明显更自然
- **导出** 1× / 4× / 8× / 12× / 16× PNG，关闭了插值，放大后仍然是干净的方块
- 列出这次实际用到的颜色，做拼豆参考图时对色很方便
- 支持点击选择、拖拽、**Ctrl+V 粘贴**三种导入方式

## 怎么用

双击 `index.html` 用浏览器打开就行，不用装任何东西，也不用联网。

想用本地服务也可以：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 它是怎么算的

1. **缩放**：原图用 canvas 的双三次插值缩到目标格数，这一步天然起到区域平均 / 抗锯齿的作用
2. **亮度对比度**：对比度用经典因子 `cf = 259 * (c + 255) / (255 * (259 - c))`
3. **调色板**
   - 自动减色：按 4bit/通道做直方图，取出现次数最多的前 K 个桶，每个桶取均值色
   - 灰阶：K 级均匀铺满 0~255
   - 其余是固定色板
4. **映射**：用 redmean 加权距离找最近色（比裸 RGB 距离更贴近人眼），并对精确 RGB 做缓存加速
5. **抖动**（可选）：Floyd–Steinberg 误差扩散，7/16、3/16、5/16、1/16

## 关于内置色卡

内置的 **MARD 291 色** 与 **优肯（ARTKAL）415 色** 拼豆色卡，来自开源项目
[Pindo](https://github.com/LunarXuan/Pindo) 和 [pindou-color-data](https://github.com/HansBug/pindou-color-data)
整理的社区色卡（品牌方不发布 HEX 值，色值是社区校对的结果）。

所以本项目用 **GPL-3.0**，跟上游色卡数据的许可保持一致，详见 [LICENSE](LICENSE)。
